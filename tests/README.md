# Tests

```
npm ci
npx playwright install chromium   # once
npm test
```

The suite opens `index.html` from disk in Chromium. It never talks to the real backend:

- every request to `script.google.com` is answered by `support/backend.js`, following `docs/API.md`;
- the CDN libraries are served from `node_modules` (same versions as in `index.html`);
- any other request is aborted and fails the test, and the browser is started with host name resolution disabled, so nothing can leave the machine.

Test MP3s and PDFs are generated by `support/media.js` when the tests run.

To change a backend reply in one test: `backend.on('audio_library', (body) => ({ items: [] }))`. Requests a test made are in `backend.calls` (`backend.callsOf('pdf_upload')`).
